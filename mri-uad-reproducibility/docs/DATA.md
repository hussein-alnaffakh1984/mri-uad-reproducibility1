# Obtaining the data

**fastMRI** (brain, multicoil): https://fastmri.med.nyu.edu/ requires a data-use agreement.

**fastMRI+** slice-level annotations: https://github.com/microsoft/fastmri-plus

Use `data/brain_split.csv` for the per-volume cohort definition. Annotation box coordinates are in the native 320 x 320 reconstruction frame.
